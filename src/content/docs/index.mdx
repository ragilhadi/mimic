## Why Mimic?

<CardGrid stagger>
	<Card title="Blazing fast" icon="rocket">
		Built with Rust and Axum. Sub-10ms response times for most requests, with under 1 second startup.
	</Card>
	<Card title="Ultra lightweight" icon="seti:rust">
		Around 1.66 MiB of memory at idle and 0.02% CPU. Comfortable on laptops, CI runners, and tiny VMs.
	</Card>
	<Card title="JSON-based mocks" icon="document">
		No config DSL to learn. One JSON file per endpoint. Drop them in a folder and Mimic picks them up.
	</Card>
	<Card title="Hot reload" icon="random">
		Edit a mock file and Mimic reflects the change immediately — no restart, no rebuild.
	</Card>
	<Card title="Advanced matching" icon="puzzle">
		Match on path parameters, query params, headers, and request body content — not just method and path.
	</Card>
	<Card title="Dynamic responses" icon="star">
		Echo request data back with `{{ }}` templating, simulate latency, return custom headers, or step through a sequence of responses.
	</Card>
	<Card title="Docker-first" icon="seti:docker">
		Prebuilt images on Docker Hub for `amd64` and `arm64`. Mount a folder of mocks and you're done.
	</Card>
</CardGrid>

## Get started in 30 seconds

```bash
docker run -d \
  --name mimic \
  -p 8080:8080 \
  -v $(pwd)/mocks:/app/mocks:ro \
  ragilhadi/mimic:latest
```

Drop a JSON file in `./mocks/` and Mimic will serve it. That's it.
